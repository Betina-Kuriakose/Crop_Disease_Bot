About CropAdvisor

CropAdvisor is a simple tool designed to give farmers fast, reliable answers about crops, soil, pests, diseases, and farming techniques — in multiple Indian languages.

What is CropAdvisor?

✔️ A chatbot for quick farming-related guidance

✔️ Uses a curated agricultural Q&A database

✔️ Supports translation for Indian languages

🔍 Information retrieval 🌾 Crop & soil management 🌐 Multi-language interface

How the system works

1. User asks a question

The query can be in English or an Indian language.

2. Language detection & translation

The text is normalised and translated to English for processing.

3. Similar question search

TF-IDF and cosine similarity find the closest matches in the Q&A dataset.

4. Intent-aware answer

Extra checks ensure safer replies for fertilizer or disease-related questions.
